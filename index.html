Baxter

A personal assistant that runs on my own computers. Registered with Google as “friday”.

Baxter is a desktop app I build and use myself. It listens when I hold a key, talks back, controls my PC, and remembers what I tell it. It is not a public service: there are no accounts, and nobody else uses it.

What it does with Google

When I connect my Gmail, Baxter can:

  • list and search my email, and read a message when I ask about it
  • write a draft reply or a new email for me to check
  • send a draft, only after I tell it to

It cannot delete or change existing mail. It asks for read and compose access only.

Where it runs

On my own Windows PC and laptop. There is no Baxter server on the internet.
